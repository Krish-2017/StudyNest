About

Made for TIT&S students.

This website uses a dark minimal interface and a TIT&S-inspired emblem based on the supplied logo. The resource organization follows the useful academic pattern of branch → semester → subject, inspired by the general structure described publicly for NotesNeo, but the branding and implementation here are original.

Important: the included notes are project-created study material, not official TIT&S course material. Verify academic content against the current syllabus and faculty resources.

How does the AI assistant work?

The browser calls /api/ai. The Node backend calls OpenAI or Gemini, so the provider key never appears in frontend code.

Can I add more branches and subjects?

Yes. Add note records and connect future uploads to secure storage and an admin moderation queue.
