# DBMS: Normalization & Normal Forms

## Normalization
Normalization organizes relational data to reduce redundancy and prevent insertion, deletion and update anomalies.

## Functional Dependency
X → Y means the value of X determines the value of Y.

## 1NF
Atomic values and no repeating groups.

## 2NF
1NF plus no partial dependency on a composite key.

## 3NF
2NF plus no transitive dependency.

## Exam tip
